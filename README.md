# Free AI Marketing Consultation Landing Page

A focused, mobile-first Next.js landing page for one action: collecting free AI marketing consultation requests.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
npm run start
```

## Deploy to Vercel

1. Push this project to a Git repository.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Keep the detected Next.js framework preset and default build command: `npm run build`.
4. Deploy. No environment variables are required for the current simulated form flow.

## Add the consultation video

The Thank You page includes a clearly marked video placeholder because no video URL or file was supplied. Replace that card in `app/thank-you/page.tsx` with your preferred embedded video when it is ready.
